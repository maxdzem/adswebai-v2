# Часть 1. Анатомия нашего сайта

## 1.1 Каркас

Next.js App Router, все маршруты под `app/[lang]/…` (локали `en`/`ru`, префикс в URL обязателен). Вёрстка — Tailwind v4 без конфига, токены в `@theme inline` внутри `globals.css`. Движение — GSAP + ScrollTrigger через `@gsap/react` (`useGSAP`), плавный скролл — Lenis, синхронизированный с ScrollTrigger через `gsap.ticker`.

Главная собрана из восьми блоков подряд, без общей обёртки с отступами — вертикальный ритм задаёт каждая секция сама:

```
Hero → ServicesGrid → AiIntro → Expertise → AnimatedCircle → ArticlesList → Contact → Footer
```

## 1.2 Палитра и типографика

| Токен | Hex | Роль |
|---|---|---|
| `cream` | `#eae8e4` | фон всей страницы; он же — текст на тёмном |
| `ink` | `#2d2d2d` | основной текст; он же — тёмные плашки |
| `mist` | `#d6d4d0` | фон внутренних страниц, на шаг темнее cream |

## 1.3 Расположение текста — вот это главное, что стоит забрать

Сайт держится не на анимациях, а на **намеренной асимметрии сетки**. Заголовки всегда прижаты влево и ограничены по мере (`max-w-[62ch]`, `max-w-[42ch]`, `lg:max-w-[14ch]` для крупных) — строка никогда не тянется во всю ширину экрана.

Приёмы, которые создают «дорогой» вид:

- **12-колоночная сетка с пропусками.** В блоке экспертизы карточки стоят на `col-span-5`, `col-start-7`, `col-start-10` — колонки 6 и 9 намеренно пустые. Дыры работают как воздух.
- **Отступ первой колонки.** `lg:col-start-2` — левая колонка начинается со второй, а не с первой. Мелочь, но убирает ощущение шаблона.
- **Ступенчатая кладка карточек.** Четыре карточки услуг получают `lg:mt-0 / mt-16 / mt-4 / mt-20` и разные пропорции (`4/5`, `3/4`, `4/3`, `4/3.4`) — ряд намеренно рваный.
- **Гигантские призрачные цифры.** `01–04` размером `clamp(3.4rem, 7.8vw, 8.4rem)`, `font-black`, `text-white/90`, свисают за верхний край плитки (`-top-[0.45em] right-1`).
- **Контурные буквы.** `.ghost-letters` — `color: transparent` + `-webkit-text-stroke: 2px rgba(45,45,45,0.28)`, размер `16vw`. Слова читаются, но не спорят с картинкой.
- **Ручные сдвиги.** `lg:ml-[12%]`, `lg:pl-[14%]`, `lg:ml-[4.5cm]` в футере — не по сетке, а на глаз.

## 1.4 Каталог движения

**Подпись-точка в навигации (главный микро-приём).** Кружок 8×8 `bg-current` стоит на `-left-[15px]` от пункта и в покое сжат в ноль. На ховер падает сверху:

```css
@keyframes dot-in {
  0%   { transform: translateY(-34px) scale(0); }
  1%   { transform: translateY(-34px) scale(1); }  /* мгновенно набирает размер за кадром */
  100% { transform: translateY(-50%)  scale(1); }
}
/* 0.4s cubic-bezier(0.175, 0.9, 0.35, 1.5) — последняя точка >1 даёт перелёт */
```

Уход — `dot-out` 0.2s ease-in. Сама подпись одновременно приседает: `label-bounce` 0.4s, `0–25% → 0`, `60% → translateY(32.5%)`, `95% → 0`, у каждого кадра свой easing. **Никаких смен цвета на ховер — только движение.** `:focus-within` продублирован рядом с `:hover`, чтобы с клавиатуры было то же самое.

**Фирменное появление секций.** Один рецепт, повторённый везде, меняются только числа:

```js
gsap.from(el, {
  y: 60–80, autoAlpha: 0, filter: "blur(10px)",
  duration: 0.9, ease: "power3.out",
  scrollTrigger: { trigger: el, start: "top 75–88%", once: true },
});
```

Карточки добавляют `delay: i * 0.08` (услуги) или `0.1` (экспертиза). Список статей мягче: `y: 28`, `blur(8px)`, `0.7s`, `power2.out`, `stagger 0.07`.

**Скролл-скраб — только два места:** баннер в AI-блоке (`y:80, scale:0.94 → 0, 1`, `scrub: 1`) и круг.

**Круг (центральный номер).** Секция `h-[160svh]`, внутри `sticky top-0 h-svh` — пин сделан CSS-ом, не GSAP-ом. Круг: `w-[150vmax] aspect-square rounded-full bg-blush`, центр на `top-[44%]`, на десктопе `lg:top-[24%]`, стартовый `scale-0`. Один таймлайн на 100 условных единиц, `scrub: 1`:

| позиция | что | параметры |
|---|---|---|
| 0 | круг | `scale 0 → 1`, длит. 38, `power1.out` |
| 10 | контент | `autoAlpha 0 → 1`, длит. 10 |
| 10 | видео-кружок | `scale 0.32 → 1`, длит. 28, `power1.out` |
| 66 | контент | `→ autoAlpha 0`, длит. 6 |
| 70 | видео-кружок | `→ scale 0.32`, длит. 26, `power2.inOut` |
| 70 | круг | `→ scale 0`, длит. 30, `power2.inOut` |

Круг схлопывается **до** того, как секция отлипнет, поэтому хвост в 160svh — мёртвый; следующая секция забирает его отрицательным полем `-mt-[75svh]`.

**Шлейф за курсором в списке статей.** Три пустые рамки `140×80` `border-ink opacity-30` и одна плитка с градиентом. Плитка привязана к курсору мгновенно (`quickSetter`), рамки отстают: `quickTo` с `duration: 0.18 + i * 0.08`, `power3.out`. Смещение от курсора `+30 / −110`. Прячется с задержкой 150 мс, чтобы не мигало между строками.

**Кнопки и ссылки.** Один приём в двух обёртках. `Button` — пилюля из трёх частей: скрытый кружок слева, подпись, кружок со стрелкой справа. На ховер за 0.3s `power3.out` подпись едет вправо ровно на ширину кружка, правая стрелка ужимается в ноль, левая разжимается из нуля. `SwapLink` — то же для текстовой ссылки. Ховер-зона — **ближайший предок с `data-btn-hover`**, поэтому наведение на любую точку карточки запускает стрелку внутри. Всё это вешается только при `matchMedia("(hover: hover)")`.

**Герой.** Строки заголовка: `y: 90, autoAlpha: 0, duration: 1.1, stagger: 0.14, delay: 0.25`, `power3.out`. Подсказка «Scroll» — бесконечный цикл: подпись приседает на 6px туда-обратно, стрелка уезжает вниз и гаснет, возвращается наверх. Плюс скраб-затухание всей подсказки на первых 160px прокрутки.

**Шапка.** Высота 100px, `fixed`, всегда прозрачная — светлое полотно это отдельный слой из 7 горизонтальных полос, которые «выключаются» глитчем как телевизор (рывки вбок кратно 8px, `ease: steps(2)`, разлёт `stagger from: "random"`, всё за ~0.3s). При скролле вниз шапка уезжает вверх, при скролле вверх возвращается (0.5s `power2.out`), порог — 100px.

**Мобильное меню.** Раскрывается эллиптической маской из точки у бургера: `clip-path: ellipse(var(--m-rx) var(--m-ry) at 88% 7.5%)`, радиусы `0% → 150%` за 0.6s `power2.out`, пункты следом `stagger amount: 0.18`. Закрытие тем же таймлайном в реверсе, но `timeScale(1.6)` — уходит резче, чем приходит.

## 1.5 Правила, без которых всё разваливается

1. `html, body { overflow-x: clip }` — именно `clip`, не `hidden`, иначе ломается `position: sticky` у круга.
2. Все полноэкранные величины — `svh`, не `vh` (адресная строка на мобильном меняет `vh` и всё дёргается).
3. `ScrollTrigger.config({ ignoreMobileResize: true })` до всего остального.
4. Анимировать только `transform`, `opacity`, `filter`, `clip-path`.
5. `prefers-reduced-motion` — глобальный демпфер на `0.01ms` (не `0`, иначе GSAP-колбэки не отработают), Lenis не создаётся вовсе.
6. Видео грузятся через IntersectionObserver с `rootMargin: 200px`, `src` присваивается скриптом — иначе три ролика тянут ~72 МБ на старте.
7. Состояние покоя всех анимируемых слоёв должно быть в разметке, а не наводиться скриптом. Иначе при сбое гидрации блок остаётся невидимым.

# Часть 2. Что менять под клининг и почему

## 2.1 Забираем без изменений

Шапка целиком, точка+подпрыгивание в навигации, выпадающие меню, обе кнопки со сменой стрелки, рецепт появления секций, ступенчатая кладка карточек с призрачными цифрами, шлейф за курсором, тёмный футер, пошаговая форма, Lenis + ScrollTrigger, вся система `svh` и reduced-motion.

## 2.2 Круг превращаем из украшения в смысл — главное предложение

У нас круг просто розовый и растёт. Для клининга это **готовая метафора, которую грех не использовать**: круг — это протёртое пятно, расползающееся по грязной поверхности.

Механика та же (`150vmax`, `sticky`, тот же таймлайн), но вместо заливки — два наложенных полноэкранных слоя одной и той же комнаты: нижний «до», верхний «после». Круг работает маской для верхнего. Прокрутил — комната стала чистой. Контурными буквами по бокам — `ЧИСТО` или `CLEAN`.

Это единственная правка, которая превращает красивый эффект в продающий, и стоит она ровно ноль: таймлайн не меняется, меняется содержимое слоёв.

## 2.3 Палитра

Кремовый и графит оставить — именно они дают ощущение «дорого и спокойно», и для клининга это работает даже лучше, чем для агентства. Менять только акценты:

| Было | Стало | Почему |
|---|---|---|
| `blush #feafe6` | мятно-водяной `#BFE9E2` | розовый читается как «агентство»; клининговые сайты поголовно уходят в аптечно-синий, приглушённая мята на тёплом кремовом выглядит гигиенично и при этом не казённо |
| `grape #4f2be8` | глубокий бирюзовый `#0F5F57` | тот же сдвиг в «воду», сохраняет контраст с белым текстом |

Кремовый и графит не трогать вообще.

## 2.4 Убавить амплитуду

Агентство может позволить себе экспериментальную вёрстку — там это часть продукта. Клиенту клининга нужно быстро найти цену и понять, что в дом пустят нормальных людей. Асимметрию сохранить, но вдвое ужать:

- ступени карточек `mt-0 / 8 / 2 / 10` вместо `0 / 16 / 4 / 20`;
- появление секций `y: 48–60`, `blur(6–8px)`, `0.7s` вместо `y: 80`, `blur(10px)`, `0.9s`;
- пропуски колонок в сетке оставить как есть — они дают воздух, а не хаос.

Точку с подпрыгиванием в навигации не трогать: она дешёвая, обаятельная и работает на любом бренде.

## 2.5 Что добавить (у нас этого нет, а клинингу нужно)

1. **Калькулятор вместо формы контакта.** Наша пошаговая карточка «один вопрос за раз» — идеальная основа. Шаги: тип уборки → площадь → санузлы → доп. услуги → срок → контакт. Цена пересчитывается живьём над кнопкой. Это самый ценный перенос: механика уже написана и отлажена, меняется только содержимое шагов.
2. **Полоса доверия** сразу под героем: количество уборок, страховка ответственности, проверенные сотрудники, гарантия перемывки. Числа отсчитываются вверх при появлении — новый приём, но в общей логике «движение вместо цвета».
3. **Ползунок «до/после»** с перетаскиваемым разделителем. Продолжает язык круга-маски.

## 2.6 Что выбросить

Канвас с частицами (слишком «технологично», в клининге читается как чужеродное), блок про AI-агентов, дробную структуру Solutions/Services — у клининга услуг мало и они плоские.

## 2.7 Подводный камень, о который вы точно споткнётесь

**У Newsreader нет кириллицы** — в нашем проекте подключена только латиница, и это нормально, потому что засечка стоит в английских строках. Если клининговый сайт русскоязычный, вторая строка героя молча упадёт на системный шрифт и вся затея с контрастом развалится.

Варианты: взять засечку с кириллицей (**Playfair Display**, **Cormorant**, **PT Serif**) либо оставить Newsreader, но держать в засечке только латинские слова. В промте ниже это учтено.

Действуй как **Senior Frontend Developer** (Next.js + GSAP).

**Контекст.** Собираем сайт клининговой компании премиального сегмента (уборка квартир, домов и офисов). Дизайн-язык уже определён и описан ниже до конкретных чисел — это не «сделай красиво», а перенос готовой системы. Ключевая идея: спокойная тёплая база, вся обратная связь — движением, а не цветом, и один крупный скролл-эффект, который показывает результат работы.

**Задача.** Собрать одностраничный сайт (главная) плюс каркас внутренних страниц.

## Стек (обязательно)

- **Next.js** (App Router) + **TypeScript**. Клиентские компоненты — только те, где нужна анимация, первой строкой `"use client"`.
- **Tailwind CSS v4** в CSS-first режиме: никакого `tailwind.config.js`, токены в `@theme inline` внутри `app/globals.css`.
- **GSAP + ScrollTrigger** через `@gsap/react` и хук `useGSAP()`. Обычный `useEffect` для таймлайнов не использовать.
- **Lenis** — плавный скролл на верхнем уровне (обёртка в `layout`), синхронизирован со ScrollTrigger: `lenis.on("scroll", ScrollTrigger.update)` + привод от `gsap.ticker` с `lagSmoothing(0)`.
- Шрифты через `next/font/google`.

Установка: `npm i gsap @gsap/react lenis`

## Дизайн-система

**Цвета** (в `@theme inline`):

```css
--color-cream: #eae8e4;   /* фон всей страницы; он же текст на тёмном */
--color-ink:   #2d2d2d;   /* основной текст; он же тёмные плашки */
--color-mist:  #d6d4d0;   /* фон внутренних страниц, на шаг темнее */
--color-fresh: #bfe9e2;   /* акцент: большой круг, аватар */
--color-deep:  #0f5f57;   /* пузырь в форме, текст на нём белый */
```

Футер — литерал `#191715`. Правило сочетаний: на светлом `text-ink` с лесенкой `/80` (подписи) `/70` `/60` (текст) `/50` `/40` (мета), линейки `border-ink/15`; на тёмном зеркально `text-cream/80…40`, линейки `border-cream/20`. `::selection` — фон `fresh`, текст `ink`.

**Шрифты.** Основной — **Inter**, подключить с subsets `["latin","cyrillic"]`. Засечка для акцентов — **Playfair Display**, subsets `["latin","cyrillic"]`, styles `["normal","italic"]`. Кириллица в засечке обязательна: акцентные строки на сайте русские, без неё они упадут на системный шрифт.

**Шкала** (в `globals.css`):

```css
.fs-display-l  { font-size: clamp(48px, 32px + 3.33333vw, 96px); }
.fs-display-m  { font-size: clamp(30px, 16px + 2.91667vw, 72px); }
.fs-display-s  { font-size: clamp(26px, 21.2px + 1.08333vw, 42px); }
.fs-body-l     { font-size: clamp(24px, 22.4px + 0.33333vw, 29px); }
.fs-body-m     { font-size: 22px; }
.fs-label      { font-size: clamp(17px, 16px + 0.16667vw, 19px); }
.type-display  { font-weight: 900; line-height: 1.15; letter-spacing: normal; }
```

Заголовок секции — всегда `type-display fs-display-m`, прижат влево, ограничен `max-w-[62ch]`. `fs-display-l` только в герое. Надзаголовки — `fs-label font-medium`.

**Засечка ставится только второй строкой пары** — вторая строка заголовка героя, подпись-подсказка (курсивом), вторая половина заголовка в списке статей. Сплошным массивом засечку не использовать.

## Структура главной

Подряд, без общей обёртки с отступами; вертикальный ритм задаёт каждая секция сама.

### 1. Шапка (`fixed inset-x-0 top-0 z-50`, высота 100px)

Слева логотип `text-[32px] font-black`; правее — кнопка выбора языка. Справа — меню `fs-label font-medium`, зазор между пунктами `gap-10`, и кнопка-пилюля «Рассчитать» (см. § Кнопка). Горизонтальные поля `px-6`, на `lg` — `px-10`.

Шапка сама всегда прозрачная. Светлое полотно — отдельный слой `-z-10` из **7 горизонтальных полос** `bg-cream`, каждая `top: (i/7)*100%`, `height: 100/7 + 0.3 %` (нахлёст 0.3 убирает щели). Внизу полотна — линия `h-px bg-black`.

Логика: на самом верху страницы полотно выключено (шапка прозрачная поверх тёмного героя, текст `text-cream`); после 100px прокрутки полотно включается, текст становится `text-ink`. Переключение — глитчем «выдернули кабель», таймлайн на паузе, ~0.3s:

| позиция | цель | твин |
|---|---|---|
| 0 | слой полотна | `opacity → 0.55`, 0.04s, `steps(1)` |
| 0.05 | слой полотна | `opacity → 1`, 0.04s, `steps(1)` |
| 0.1 | полосы | `x → random(-64, 64, 8)`, `scaleX → random(0.2, 0.9, 0.1)`, `transformOrigin` случайно left/right center, 0.12s, `steps(2)`, `stagger { each: 0.012, from: "random" }` |
| 0.1 | линия | `scaleX → 0.3`, 0.06s, `steps(1)` |
| 0.2 | полосы | `opacity → 0`, 0.08s, `steps(1)`, `stagger { each: 0.01, from: "random" }` |
| 0.22 | линия | `opacity → 0`, 0.05s, `steps(1)` |

Включение — тот же таймлайн в реверсе.

**Важно:** состояние покоя полос (скрыты) задать классами в разметке, а не только скриптом. Цвет текста и видимость полотна должны следовать из одного состояния — иначе при сбое получится текст `cream` на фоне `cream`, то есть невидимая шапка.

При скролле вниз шапка уезжает вверх (`yPercent: -100`, 0.5s `power2.out`), при скролле вверх возвращается; до 120px всегда видна.

**Появление при загрузке:** контейнер `autoAlpha 0 → 1` за 0.3s, затем пункты `y: 30, autoAlpha: 0 → 0`, 0.5s, `stagger 0.05`, `power2.out`, обязательно `clearProps: "all"` (иначе останется инлайновый transform и сломаются CSS-ховеры).

### 6. Круг-протирка — центральный эффект

Две части подряд.

**Вводный блок** (обычный поток): `bg-cream px-6 pb-[2cm] pt-36 lg:px-10`, внутри `lg:ml-[12%]`, надподпись `fs-label font-medium` и заголовок `type-display fs-display-m mt-5 max-w-[42ch]`. Без анимации.

**Липкая секция:** `<section class="h-[160svh] bg-cream">` (именно `160svh`; секция **не** `relative`). Внутри `<div class="pointer-events-none sticky top-0 h-svh">` — пин делается CSS-ом, `ScrollTrigger.pin` не использовать. Без `overflow-hidden`.

Внутри липкого слоя два наложенных полноэкранных изображения одной и той же комнаты: нижний слой — «до» (тусклый, пыльный), верхний — «после» (светлый, чистый). Верхний слой **обрезан кругом**, и этот круг растёт при прокрутке. Растущий элемент: `absolute left-1/2 top-[44%] lg:top-[24%] aspect-square w-[150vmax] -translate-x-1/2 -translate-y-1/2 scale-0 rounded-full` — диаметр `150vmax` при диагонали экрана ~141vmax гарантирует полное перекрытие из любого центра.

Поверх — слой контента (отдельный элемент, **не** внутри масштабируемого круга, иначе его растянет): `absolute inset-0 opacity-0`.

По бокам — контурные слова: `color: transparent; -webkit-text-stroke: 2px rgba(45,45,45,0.28)`, размер `lg:text-[16vw]` (на мобильном `20vw` и колонкой). Слова: `ЧИСТО` слева, справа — название компании. Между ними на десктопе распорка `lg:w-[34vw]` под круг.

Подпись внизу слева (`lg:left-[14vw] lg:top-[63%]`): плашка `fs-label inline-block rounded-[50%] border border-ink/70 px-5 py-2 font-medium` (именно `rounded-[50%]` — эллипс, не стадион), под ней две строки `fs-body-m`, вторая `text-ink/50`.

Таймлайн — один, `defaults: { ease: "none" }`, `scrollTrigger: { trigger: секция, start: "top 90%", end: "bottom bottom", scrub: 1 }`, длительности как доли от 100:

| позиция | цель | твин |
|---|---|---|
| 0 | круг | `scale 0 → 1`, длит. 38, `power1.out` |
| 10 | слой контента | `autoAlpha 0 → 1`, длит. 10 |
| 66 | слой контента | `→ autoAlpha 0`, длит. 6 |
| 70 | круг | `→ scale 0`, длит. 30, `power2.inOut` |

### 7. Отзывы — `-mt-[75svh] bg-cream px-6 pb-40 pt-28 lg:px-10`

**Отрицательное поле обязательно:** круг схлопывается раньше, чем кончается его 160svh, и `-mt-[75svh]` подтягивает эту секцию под мёртвый хвост. Задавать в `svh`, не в сантиметрах — иначе поедет на других экранах.

Заголовок `type-display fs-display-m`. Ниже список `mt-16 divide-y divide-current` — линейки только между строками.

Строка: `flex flex-col gap-3 py-6 md:flex-row md:items-center md:gap-6`, помечена `data-btn-hover`. Внутри: район или тип объекта `fs-label font-medium md:w-44 md:shrink-0`; текст отзыва `fs-body-m min-w-0 font-medium leading-[1.15] md:flex-1 md:truncate`, где вторая половина фразы — `<em class="font-serif font-normal not-italic">` (засечка обычного начертания, **не** курсив); дата `fs-label md:w-32 md:shrink-0`; кнопка «Читать».

**Шлейф за курсором.** При наведении на строку у курсора появляется плитка с фото объекта и три пустые рамки, тянущиеся за ней:
- контейнер `pointer-events-none fixed left-0 top-0 z-[70] opacity-0`;
- рамки — три штуки `absolute h-[80px] w-[140px] rounded-[4px] border border-ink opacity-30`, плитка — того же размера с фото;
- смещение от курсора `+30` по X, `−110` по Y;
- плитка следует мгновенно (`gsap.quickSetter`), рамки — `gsap.quickTo` с `duration: 0.18 + i * 0.08`, `power3.out`, отсюда эффект хвоста;
- показ мгновенный, скрытие с задержкой 150 мс и затуханием 0.15s — иначе мигает при переходе между строками;
- вешать только при `matchMedia("(hover: hover)")`.

Появление: заголовок `y: 40, autoAlpha: 0, blur(8px), 0.7s, power2.out`, `start: "top 85%"`; строки — триггер на **контейнере**, `y: 28, autoAlpha: 0, blur(8px), 0.7s, stagger: 0.07`, `once: true`.

### 8. Калькулятор — `id="calc"`, `bg-cream px-6 pb-[2cm] pt-20 lg:px-10 lg:pt-36`

Сетка `grid grid-cols-1 gap-20 lg:grid-cols-2`.

Слева заголовок `type-display fs-display-m lg:max-w-[14ch]`.

Справа сверху — «диалог»: кружок-аватар `grid h-20 w-20 sm:h-24 sm:w-24 shrink-0 place-items-center rounded-full bg-fresh shadow-lg` и рядом пузырь `fs-body-m max-w-md rounded-2xl bg-deep p-5 leading-relaxed text-white` с хвостиком-кружком `absolute -bottom-4 -left-3 h-3.5 w-3.5 rounded-full bg-deep`. На мобильном аватар встаёт над пузырём.

Ниже (`mt-10 lg:mt-16 lg:pl-32`) — **калькулятор по одному вопросу за раз**. Карточка: `w-full max-w-xl cursor-text overflow-hidden rounded-[32px] border border-ink/80 bg-white px-5 py-6 sm:px-8 sm:py-7 shadow-[0_18px_40px_-24px_rgba(45,45,45,0.45)]`; клик в любое место карточки ставит фокус в поле.

Шаги: тип уборки (радио) → площадь в м² (число) → количество санузлов (число) → доп. услуги (мультивыбор: окна, холодильник, духовка, балкон) → желаемая дата → имя → телефон. Обязательные — все, кроме доп. услуг.

Над кнопкой отправки — **живая цена**, пересчитывается на каждом шаге; при изменении число меняется отсчётом за 0.4s, а не скачком.

Под карточкой ряд: точки прогресса `h-2.5 w-2.5 rounded-full transition-colors duration-300` — пройденные `bg-ink/35`, текущая `bg-ink`, будущие `border border-ink/25`; справа круглая кнопка `grid h-[72px] w-[72px] place-items-center rounded-full transition-all duration-300 hover:scale-105`, на последнем шаге `bg-ink text-white`, иначе `bg-white text-ink`.

Радио-вариант: `group flex cursor-pointer items-center gap-4 py-2`, кружок `h-[22px] w-[22px] shrink-0 rounded-full border-2 transition-all duration-200`, выбранный `border-ink bg-ink`, обычный `border-ink/35 group-hover:border-ink`.

Смена шага:
- вход — высота карточки `fromTo(предыдущая → фактическая, 0.45s, power3.out, clearProps: "height")` в позиции 0; поле `fromTo({ y: 26, autoAlpha: 0 }, { y: 0, autoAlpha: 1, duration: 0.45, power3.out })` в позиции 0.08;
- выход — `y: -26, autoAlpha: 0, duration: 0.28, power2.in`, следующий шаг ставится в `onComplete`, на время перехода блокировать повторные нажатия;
- ошибка валидации — карточка вздрагивает: `fromTo({ x: -8 }, { x: 0, duration: 0.5, ease: "elastic.out(1, 0.35)" })`.

Появление секции (триггер — секция, `start: "top 72%"`, `once: true`): текстовые элементы `y: 50, autoAlpha: 0, blur(8px), 0.7s, stagger: 0.12, power3.out`; аватар разворачивается `rotationY: -100, autoAlpha: 0, transformPerspective: 700, duration: 0.9, delay: 0.15, power3.out`; пузырь надувается от хвостика `scale: 0.7, autoAlpha: 0, transformOrigin: "0% 100%", duration: 0.6, delay: 0.45, ease: "back.out(1.6)"`.

## Общие элементы

### Точка-маркер и подпись в навигации

Главный микро-приём сайта. Кружок `8×8`, `bg-current`, `absolute -left-[15px] top-1/2`, `pointer-events-none`, в покое сжат.

```css
.nav-dot { transform: translateY(-50%) scale(0); }

@keyframes dot-in {
  0%   { transform: translateY(-34px) scale(0); }
  1%   { transform: translateY(-34px) scale(1); }
  100% { transform: translateY(-50%)  scale(1); }
}
@keyframes dot-out {
  0%   { transform: translateY(-50%) scale(1); }
  100% { transform: translateY(-50%) scale(0); }
}
@keyframes label-bounce {
  0%, 25% { transform: translateY(0);     animation-timing-function: cubic-bezier(.25,.46,.45,.94); }
  60%     { transform: translateY(32.5%); animation-timing-function: cubic-bezier(.25,.46,.45,.94); }
  95%     { transform: translateY(0);     animation-timing-function: cubic-bezier(.55,.085,.68,.53); }
}

.nav-item:hover .nav-dot,
.nav-item:focus-within .nav-dot { animation: dot-in .4s cubic-bezier(.175,.9,.35,1.5) 0s 1 forwards; }
.nav-item:not(:hover):not(:focus-within) .nav-dot { animation: dot-out .2s ease-in 0s 1 forwards; }
.nav-item:hover .nav-label { animation: label-bounce .4s linear 0s 1; }
```

Последняя контрольная точка `1.5` в `dot-in` даёт перелёт — это и есть «характер». `:focus-within` дублируется рядом с `:hover` обязательно. **Цвет на ховер не меняется нигде — только движение.**

### Кнопка-пилюля

Три части без зазоров: скрытый кружок слева (`absolute left-0 scale-0`), подпись-пилюля, кружок со стрелкой справа. Размер `md`: кружки `40×40`, минимальная ширина подписи `104px`, текст `fs-label`, иконка 16px. Размер `lg`: `56×56`, `148px`, `fs-body-m`, 20px. Скругление `rounded-[100px]`, подпись `px-[15px] font-medium`.

Ховер — один таймлайн на паузе, `defaults: { duration: 0.3, ease: "power3.out" }`, все три твина в позиции 0:

```js
tl.to(label,      { x: iconWidth }, 0)
  .to(arrowRight, { scale: 0, x: iconWidth }, 0)
  .fromTo(arrowLeft, { scale: 0 }, { scale: 1 }, 0);
```

`iconWidth` замерять в рантайме через `offsetWidth` правого кружка, не хардкодить. Плюс `transition-transform duration-150 active:scale-[0.96]` для отклика на тапе.

### Текстовая ссылка со стрелкой

Тот же приём для ссылки внутри карточки: `[скрытый кружок][слово][кружок со стрелкой]`, `display: inline-flex`. На ховер за 0.3s `power3.out` слово едет вправо ровно на `размер + зазор`, правая стрелка гаснет (`autoAlpha: 0, scale: 0.4, x: 8`), левая разжимается из нуля.

**Ховер-зона — ближайший предок с атрибутом `data-btn-hover`** (искать через `element.closest()`), а не сама ссылка. Поэтому наведение на любую точку карточки запускает стрелку внутри неё.

Все ховер-обработчики вешать только при `window.matchMedia("(hover: hover)").matches` — иначе на тач-экране слово залипнет сдвинутым.

## Жёсткие правила

1. Анимировать **только** `transform`, `opacity`, `filter`, `clip-path`. Никогда `width`/`height`/`top`/`left`.
2. `html, body { overflow-x: clip }` — именно `clip`, не `hidden`: `hidden` ломает `position: sticky` у круга.
3. Все полноэкранные величины — `svh`, не `vh`.
4. `ScrollTrigger.config({ ignoreMobileResize: true })` вызвать до всего остального.
5. Каждое появление секции — `once: true`. Скраб только у круга.
6. Состояние покоя анимируемых слоёв задавать классами в разметке; скрипт только переключает. Ни один блок не должен становиться невидимым, если JS не отработал.
7. `prefers-reduced-motion: reduce` — глобально `animation-duration: .01ms !important`, `transition-duration: .01ms !important` (именно `.01ms`, не `0`, иначе GSAP-колбэки не сработают); Lenis не создавать вовсе.
8. Видео подключать через IntersectionObserver с `rootMargin: "200px"`, присваивая `src` скриптом, а не в разметке; ставить на паузу вне экрана; не запускать при reduced-motion.
9. В `<html>` и `<body>` добавить `suppressHydrationWarning` — расширения браузера дописывают туда атрибуты и роняют гидрацию.

## Как дорабатывать

- Круг раскрывается рано или поздно — менять `start`/`end` у его ScrollTrigger либо длительности внутри таймлайна (сумма = 100).
- После круга появился провал — подкрутить `-mt-[75svh]` у следующей секции.
- Появление секций слишком резкое — уменьшать `y` и радиус `blur`, а не длительность.
- Шапка мигает при загрузке — проверить, что состояние покоя полос задано классом в разметке, а не только скриптом.
