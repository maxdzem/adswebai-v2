# monks-clone — материалы для аналога «circle reveal»

Всё для воссоздания эффекта с monks.com: **круглое видео с лицом, которое при скролле
увеличивается, пока буквы «monks» разъезжаются в стороны.**

## Что внутри
```
monks-clone/
├── storyboard/
│   ├── 01-start.png    — круг въезжает (средний, по центру)
│   ├── 02-middle.png   — круг растёт
│   └── 03-end.png      — максимум (крупный круг, буквы разъехались)
├── public/             — сюда положи face-video.mp4
├── PROMPT.md           — ГОТОВЫЙ идеальный промт под Next.js
├── TECH-STACK.md       — разбор стека monks.com + стек для клона
├── styles.txt          — дизайн-токены (цвета/шрифты/параметры круга)
└── README.md           — этот файл
```

## Как пользоваться
1. **Скачай видео лица.** Открой monks.com → DevTools (F12) → вкладка **Network** →
   фильтр **Media** → долистай до блока с Сорреллом → сохрани `.mp4` →
   положи как `public/face-video.mp4`.
2. **Собери код.** Открой Claude → **прикрепи** `storyboard/01-start.png`,
   `02-middle.png`, `03-end.png` → вставь текст из **`PROMPT.md`**.
3. Claude выдаст компоненты Next.js → вставь в проект → `npm i gsap @gsap/react lenis` → запусти.

## Важно про раскадровку
В записи экрана круг растёт от **среднего до крупного** (не на весь экран) — это умеренный
scale-up + разъезжающиеся буквы. В `PROMPT.md` финальный радиус вынесен в константу:
`circle(75%)` = как на monks, `circle(100%)` = фуллскрин-раскрытие.
